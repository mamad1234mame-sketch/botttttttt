# 🧬 Bio with AI — ناشر خودکار کانال تلگرام

یک ربات کاملاً self-hosted که برای کانال علمی **AI × زیست‌شناسی** پست تولید و
منتشر می‌کند. روی **GitHub Actions** اجرا می‌شود، یعنی **بدون سرور، بدون
هزینهٔ ماهانه**.

```
سیگنال زنده  →  انتخاب قالب  →  نوشتن با Gemini  →  تصویر  →  ارسال به تلگرام
 (ترندها،        (۱۵ قالب          (Grounding +        (Nano      (HTML امن،
  PubMed،        متفاوت،           JSON سخت‌گیرانه)     Banana)    تکه‌بندی،
  bioRxiv)       بدون تکرار)                                        دکمه)
```

## نصب سریع

```bash
git clone <repo-url> && cd bio-ai-channel
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env   # و پرش کن
pytest                 # ۱۶۱ تست، بدون شبکه
```

اجرای دستی:

```bash
set -a; source .env; set +a

python -m bioai_channel.main --selftest           # بررسی اتصال بات و کانال
python -m bioai_channel.main --dry-run            # بنویس ولی نفرست
python -m bioai_channel.main --format fact        # یک پست دانستنی
python -m bioai_channel.main --no-image           # بدون تصویر (صرفه‌جویی سهمیه)
```

راهنمای کامل راه‌اندازی روی گیت‌هاب: [`SETUP.md`](SETUP.md)

## نکات فنی که در کد حل شده‌اند

**حد ۴۰۹۶ کاراکتر.** تلگرام متن را *بعد از parse شدن entityها* می‌شمارد، پس
تگ‌های HTML حساب نمی‌شوند ولی متن دیده‌شده حساب می‌شود. تکه‌کننده دقیقاً بر
همین اساس کار می‌کند و هرگز وسط تگ یا URL نمی‌بُرد.

**`can't parse entities`.** با `parse_mode=HTML` یک `<` ساده در `p < 0.05` کل
پیام را رد می‌کند. سانیتایزر فقط تگ‌های مجاز تلگرام را نگه می‌دارد، بقیه را
escape می‌کند، تگ‌های بسته‌نشده را می‌بندد، و اگر باز هم تلگرام نپذیرفت،
به‌صورت خودکار بدون `parse_mode` می‌فرستد.

**مدل‌های در حال بازنشستگی.** مدل پیش‌فرض `gemini-3.7-flash` است (stable).
اگر مدلی روی اکانت تو موجود نبود، به‌صورت خودکار مدل‌های جایگزین امتحان
می‌شوند.

**سهمیهٔ رایگان.** هر اجرا ۲ تا ۳ فراخوانی Gemini مصرف می‌کند. با اجرای هر
۳ ساعت، حدود ۲۴ فراخوانی در روز — بسیار کمتر از سقف لایهٔ رایگان.
