# state/

این پوشه حافظهٔ پایدار کانال است.

- `memory.json` — تاریخچهٔ پست‌های منتشرشده. GitHub Actions بعد از هر اجرا
  خودش این فایل را کامیت می‌کند تا پست بعدی تکراری نباشد.
- `heartbeat.txt` — فقط برای زنده نگه داشتن زمان‌بند گیت‌هاب.

هیچ‌کدام را دستی ویرایش نکن مگر اینکه بدانی چه می‌کنی.

اگر خواستی حافظه را صفر کنی (مثلاً برای شروع تازه):

```bash
rm state/memory.json
git commit -am "chore: reset memory"
git push
```
